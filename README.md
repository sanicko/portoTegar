# Muhammad Tegar Pratama — Portfolio

A responsive, bilingual, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser, or run a local server from this directory:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The original CV PDF is served from `assets/muhammad-tegar-pratama-cv.pdf`.
